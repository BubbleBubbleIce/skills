# Decision Records

Significant engineering decisions and their later corrections. Search the index by topic and open only the relevant records.

## Index

| ID | Status | Topic | Related clauses |
|---|---|---|---|
| [0001](0001-short-title.md) | accepted | <Topic> | <AREA-001> |

## Adding a record

1. Use the next four-digit number and a short English file name: `NNNN-short-title.md`.
2. Fill in status, date, context, decision, rationale, alternatives, consequences, acceptance, and related clauses, following the structure of an existing record.
3. When a decision is overturned, keep the old file. The new record declares `supersedes`, and the old one gains `superseded by`.
4. Discussions that didn't produce a choice don't belong here. Unfinished actions go to [NOW.md](../NOW.md).
